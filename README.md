# TeamDocs Explorer — releases

This repository hosts release builds of the **TeamDocs Explorer** Obsidian plugin for
installation via [BRAT](https://github.com/TfTHacker/obsidian42-brat).

## Install

1. Install the **BRAT** plugin from the Obsidian community plugin store.
2. In BRAT settings, choose **Add beta plugin** and enter `AVeryLostNomad/teamdocs-releases`.
3. Enable **TeamDocs Explorer** in Settings → Community plugins.

No source code lives here — each GitHub Release carries the built
`main.js`, `manifest.json`, and `styles.css`.
